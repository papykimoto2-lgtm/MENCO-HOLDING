# Manuel de procédures — Réunions de direction

**Réf.** PRO-REU · **Version** 1.0 · **Date** Octobre 2026
**Objet** : fixer qui fait quoi pour planifier une réunion de direction, convoquer, préparer l'ordre du jour, tenir la séance, produire le procès-verbal, le diffuser et suivre les actions.
**Principe directeur** : pas de réunion sans participants, thèmes et animateur ; pas de PV sans présence, décisions et actions responsabilisées ; chaque action a un responsable et une échéance.

> Les noms de boutons sont ceux du module **Réunions de Direction** (Tableau de bord, Planifier, Convocations, Préparation, Réunion, PV & Actions, Diffusion, Suivi Actions, Analyse 360°).

---

## 1. Rôles

| Rôle | Responsabilités |
|---|---|
| **Animateur** | Planifie, préside, clôture |
| **Secrétaire** | Convoque, prépare l'ordre du jour, relit le PV |
| **Participants** | Confirment leur présence, exécutent leurs actions |
| **Direction** | Valide le PV et diffuse |

## 2. Règles d'or

1. Une réunion exige **titre, date et animateur**, au moins **un participant** et au moins **un thème 360°**.
2. La **convocation** précède la réunion ; le statut de chaque convoqué se suit : en attente, confirmé, excusé.
3. À la clôture, le **PV est généré automatiquement** : relire avant diffusion.
4. Chaque **action** a un **responsable** et une **échéance**.
5. Les décisions, actions, présences et confirmations d'une réunion reprise ne se recopient **jamais**.

## 3. Procédures

### REU-01 — Planifier

**Où** : Planifier › **+ Nouvelle Réunion**.

| Champ | Contenu |
|---|---|
| **Titre, date, animateur** | Obligatoires |
| Type, périodicité, durée, lieu, division | Cadre |
| **Participants** | Choisis dans le personnel (nom — fonction) ou saisis hors liste ; **tout le personnel** disponible peut être ajouté |
| **Thèmes 360°** | Au moins un |
| Objectifs, documents | Préparation |

1. Pour une réunion récurrente, **Reprendre une réunion précédente** : cadre, participants, thèmes, objectifs et documents sont recopiés, la **prochaine date** est proposée, la nouvelle réunion repart vierge.
2. Enregistrer : statut « planifiée ».

### REU-02 — Convoquer

**Où** : Convocations.

1. Choisir la réunion ; **4 modèles** de message : convocation, rappel, relance, rectificatif.
2. Envoi personnalisé ou **« envoyer au suivant »** ; e-mail groupé ; fichier **calendrier (ICS)** ; WhatsApp.
3. Suivre les statuts : **en attente**, **confirmé**, **excusé** ; vérifier le **quorum**.
4. **Relancer les absents** : un modèle de relance est préparé pour les participants sans réponse.

### REU-03 — Préparer

**Où** : Préparation : ajouter les points de l'**ordre du jour**, joindre les documents ; enregistrer.

### REU-04 — Tenir la séance

**Où** : Réunion.

1. Pointer la **feuille de présence** ; excusés indiqués.
2. Traiter chaque point de l'ordre du jour (case « traité »).
3. Saisir **décisions** et **actions** (responsable, échéance), et les notes de séance.
4. **Clôturer la séance** : confirmation, statut « tenue ».

### REU-05 — Procès-verbal

**Où** : PV & Actions.

1. Le PV est créé automatiquement à la clôture : numéro unique, résumé, décisions, actions, prochaine date proposée ; excusés et ordre du jour repris.
2. Le **contrôle de complétude** signale : aucun présent pointé, points non traités, aucune décision, actions sans responsable ou sans échéance, résumé vide.
3. Corriger, rédiger le résumé (aide à la rédaction : suggestions cliquables) ; relire le PV avant diffusion.

### REU-06 — Diffuser

**Où** : Diffusion : seules les séances **clôturées** apparaissent ; envoyer le PV aux participants.

### REU-07 — Suivre les actions

**Où** : Suivi Actions : lire les actions par responsable et échéance ; marquer les actions faites ; relancer les retards.

### REU-08 — Analyse 360° et tableau de bord

**Où** : Analyse 360°, Tableau de bord : lecture transversale des réunions et des actions ; à lire avant chaque comité.

## 4. Contrôles

| Contrôle | Effet |
|---|---|
| Titre, date ou animateur absent | Réunion refusée |
| Aucun participant ou aucun thème | Réunion refusée |
| PV incomplet | Problèmes listés avant diffusion |
| Réunion non clôturée | Absente de la diffusion |

## 7. Erreurs fréquentes

| Symptôme | Cause | Action |
|---|---|---|
| Liste de diffusion vide | Aucune séance clôturée | Clôturer la séance |
| PV avec problèmes | Présence ou actions incomplètes | Compléter puis revalider |
| Réunion sans participants | Personnel non choisi | Ajouter des participants |

## 8. Liste de contrôle

1. ☐ Convocation envoyée, confirmations suivies
2. ☐ Ordre du jour préparé
3. ☐ Présences pointées
4. ☐ Décisions et actions responsabilisées
5. ☐ PV relu, diffusé
6. ☐ Actions suivies jusqu'à leur clôture
