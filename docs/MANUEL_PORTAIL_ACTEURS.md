# Manuel de procédures — Portail des acteurs (usage et assistance)

**Réf.** PRO-POR · **Version** 1.1 · **Date** Octobre 2026
**Objet** : fixer comment les acteurs externes se connectent à leur espace du portail et comment le personnel les accompagne. L'émission des codes est traitée dans PRO-ADM (ADM-09).
**Principe directeur** : chaque acteur n'accède **qu'à son propre espace**, avec un **code personnel** transmis par un canal distinct de son identifiant.

> Les noms sont ceux du portail unique. Chaque espace est décrit d'après son écran.

---

## 1. Espaces disponibles

Souscripteur · Intervenant · Apporteur d'affaires · Investisseur diaspora · Acquéreur foncier · Propriétaire mandant · Propriétaire terrien · Partenaire lotissement · Partenaire financier · Aménageur · Locataire · Copropriétaire.

## 2. Rôles

| Rôle | Responsabilités |
|---|---|
| **Acteur externe** | Se connecte, consulte, envoie ses observations ou déclarations |
| **Commercial / gestionnaire** | Accompagne l'acteur, relaie ses demandes |
| **Administrateur** | Émet et réinitialise les codes (PRO-ADM) |

## 3. Règles d'or

1. Connexion = **identifiant + code d'accès** de l'espace concerné.
2. Le code est personnel : le personnel ne le demande jamais à l'acteur.
3. Les codes sont stockés **hachés** ; un code perdu se **réémet**, il ne se relit pas.
4. Après **5 tentatives** en 10 minutes, la connexion est bloquée temporairement.
5. L'acteur se **déconnecte** après usage, surtout sur un appareil partagé.
6. Les demandes de l'acteur passent par la **messagerie** de l'espace, pas par un canal privé.

## 4. Procédures

### POR-01 — Première connexion

1. L'acteur ouvre l'onglet de son espace.
2. Souscripteur : identifiant = n° de dossier, e-mail ou téléphone, plus le code reçu de son commercial.
3. Autres espaces : identifiant propre à l'espace, plus le code reçu des services.
4. Cliquer **Se connecter** ; un message d'erreur s'affiche sous le champ en cas d'échec.

### POR-02 — Connexion refusée

1. Vérifier l'espace choisi (onglet) et l'identifiant.
2. Vérifier que l'acteur a un code émis (PRO-ADM, ADM-09).
3. Réémettre le code si besoin ; ne jamais le communiquer avec l'identifiant sur le même message.

### POR-03 — Souscripteur

Accueil nominatif ; sections **Finances**, **Documents**, **Travaux**, **Versements**, **Échéancier**, **Messagerie** ; attestation de versements et échéancier personnalisé à consulter ou imprimer.

### POR-04 — Apporteur d'affaires

**Clients apportés**, **commissions**, **messagerie**.

### POR-05 — Acquéreur foncier

Consultation et impression de l'attestation ; envoi d'une **déclaration** de paiement.

### POR-06 — Intervenant (notaire, prestataire)

1. Consulter les dossiers confiés : attestations à consulter ou imprimer, pièces à ouvrir (lien temporaire), messages.
2. Pour chaque mission : **Accepter** (confirmation demandée ; ne remplace pas un contrat), **Démarrer**, déposer les **livrables**, **Soumettre** pour vérification, **Reprendre** si la mission est renvoyée.
3. Dépôt d'un livrable : indiquer une **référence** (obligatoire) ou joindre un **fichier** PDF, JPG, PNG ou WebP de **5 Mo au plus**, avec une note.
4. Soumettre avec des livrables sans version déposée demande une confirmation.
5. Une mission clôturée est en **lecture seule** ; **Demander des informations** écrit au service.
6. Consultations et ouvertures de pièces sont **journalisées**.

### POR-07 — Investisseur diaspora

Onglets **Séquestre**, **Preuves**, **Co-investisseurs**, **Payer**.

1. **Payer et placer en séquestre** : montant **minimum 1 000 FCFA**, puis redirection vers la page de paiement ; en cas d'échec, réessayer.
2. **Re-vérifier maintenant** relance le contrôle de la chaîne de preuve.
3. Aucun dossier d'investissement : contacter le gestionnaire (PRO-DIA).

### POR-08 — Propriétaire mandant

Onglets **Compte de gestion**, **Mes biens**, **Quittances**, **Reversements** ; **Imprimer le relevé** produit le relevé de gestion locative (PRO-LOC).

### POR-09 — Propriétaire terrien

Pour chaque site apporté : localisation, superficie, qualité, **étape actuelle**, jalons (accord de principe, vérification des droits coutumiers, validation juridique), travaux, démarches administratives, lots du collège de propriétaires.

### POR-10 — Partenaire lotissement

Pour chaque terrain confié : localisation, superficie, lots prévus, date de confiage, **avancement global et par étape**, rapports de chantier (photos, vidéo), documents.

### POR-11 — Partenaire financier

Onglets **Versements**, **Documents**, **Déclarer un versement** : saisir un montant **supérieur à 0**, référence et notes ; la déclaration est **vérifiée puis validée par l'administration** (PRO-FON, PRO-PTF).

### POR-12 — Aménageur

Pour chaque convention : objet, dates, montant HT, retenue de garantie, avance de démarrage, statut, **avancement des travaux** et **situations de travaux** (date, avancement, montant HT, retenue, statut) ; synthèse : montant confié, avancement moyen, situations réglées, reste à régler (PRO-AME).

### POR-13 — Locataire

1. **Votre situation** : à jour ou somme restant à régler ; loyer, périodicité, dépôt de garantie, total réglé.
2. **Payer maintenant** : confirmer le montant de la période, puis page de paiement en ligne ; si le paiement est indisponible, un message donne le numéro à appeler.
3. **Mes quittances** : historique avec statut (partielle, à régler, jours de retard) ; impression.
4. **Mon contrat**.
5. **Signaler un incident** : nature du problème obligatoire, description d'au moins 10 caractères, urgence ; le signalement est traité par le gestionnaire locatif (PRO-LOC).

### POR-14 — Copropriétaire

Résidence, lot, tantièmes ; **total appelé, réglé, solde dû** ; **appels de charges** et **fonds travaux** ; ordre du jour des assemblées (PRO-COP).

### POR-15 — Déconnexion

Cliquer **Déconnexion** : la session est vidée et l'écran de connexion réapparaît.

### POR-16 — Répondre aux messages

1. Lire les messages des acteurs dans la messagerie interne.
2. Répondre sous le délai convenu en interne ; traiter la demande dans le module concerné.

## 5. Traçabilité

Messages et déclarations sont enregistrés et rattachés à l'acteur.

## 7. Erreurs fréquentes

- Choisir le mauvais espace.
- Envoyer identifiant et code ensemble.
- Laisser une session ouverte sur un poste partagé.
- Demander le code à l'acteur au lieu de le réémettre.
